REAL PRODUCTION CODE (lib/db/cr-artifacts.ts, verbatim) and the semantics behind every /categories page: stale weeks carry forward with an as_of stamp rather than zeroing. The trap is (c): a target BEFORE the earliest artifact returns null, not the earliest week — models that reach for 'closest week' instead of reading `week <= $2` get it wrong.
